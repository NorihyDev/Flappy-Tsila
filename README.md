# Flappy TSILA

Flappy TSILA is an Android game inspired by the classic Flappy Bird, developed in C# using .NET MAUI and Visual Studio 2022.

## Developer

**Norihy**

## About the Game

Control TSILA and try to pass through as many pipes as possible to achieve the highest score.

The game includes:

* Jump mechanics
* Gravity system
* Moving pipes
* Real-time score tracking
* Game Over screen
* Restart button
* Custom user interface
* Android APK support

## Technologies Used

* .NET MAUI
* C#
* XAML
* Visual Studio 2022
* Android SDK

## How to Play

* Tap the screen to make TSILA jump.
* Avoid hitting the pipes.
* Try to beat your highest score.

## Build Instructions

Recommended configuration:

* Release
* net10.0-android

Publish command:

```bash
dotnet publish -f net10.0-android -c Release
```

## APK Location

The signed APK is generated in:

```text
bin\Release\net10.0-android\publish\
```

Example:

```text
com.companyname.flappytsila-Signed.apk
```
